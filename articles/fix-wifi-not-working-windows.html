How to Fix Wi-Fi Not Working on Windows

Updated October 26, 2026 · 6 min read · TechFixDesk Editorial Team

When Wi-Fi stops working, first identify whether other devices can connect. This helps separate a router or internet issue from a problem on one PC.

🪟
Before you begin: Save your work and back up important data before making system-level changes. Use official software sources and stop if a step does not match your device.

1. Test another device

Connect a phone or another computer to the same Wi-Fi. If all devices are offline, restart the router using its normal power procedure and contact your internet provider if needed.

2. Toggle Wi-Fi and Airplane mode

Make sure Airplane mode is off and Wi-Fi is on. Disconnect and reconnect to the network, then restart the PC.

3. Forget and reconnect

In Settings → Network & internet → Wi-Fi → Manage known networks, select your network and choose Forget. Reconnect with the correct password.

4. Run network diagnostics

Use Windows network troubleshooting from Settings. If the issue began after a driver update, check Device Manager and consider the manufacturer’s supported driver.

5. Reset networking only later

A network reset can remove saved adapters and settings. Use it only after simpler checks and make sure you know your Wi-Fi password and any work VPN requirements.

Key takeaway: If several devices lose internet at once, investigate the router or service before changing Windows drivers.

When to get more help

If the problem persists, note the exact error message, device model, operating-system version, and steps you already tried. Use the official support channel for your device or application, especially for account access, warranty, or data-recovery issues.
